# Proveniência dos scripts

Fonte: `spotify-exportacao.zip`, exportado do BigQuery em 22/11/2026.

- `01_preparacao_dados.sql`, `02_integracao_views.sql`, `04_correlacoes.sql` e `05_indicadores_dashboard.sql`: consultas recuperadas do histórico de jobs; comentários e agrupamento adicionados para apresentação.
- `03_analise_exploratoria.sql` e `06_validacoes.sql`: consultas organizadas para facilitar reprodução e conferência, não transcrições literais do histórico.
- Não foram incluídos os CSVs com dados completos nem o histórico integral de jobs no repositório público.
- Resultados e SQL devem ser reexecutados no BigQuery para validação de ponta a ponta.
